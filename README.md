## 🌟 About The Project

Number Guessing Game is a simple and interactive game developed using Python.
The computer generates a random number, and the player tries to guess it
correctly through the terminal.

## ✨ Features

- 🎲 Random Number Generation
- 🔢 Guess the Secret Number
- 💡 Helpful Hints
- 🖥️ Simple Terminal Interface
- 🐍 Beginner-Friendly Python Project
