## 🌌 01 — ABOUT THE GAME

🎯 **Can you guess the secret number?**

Number Guessing Game is a simple and fun Python project where the computer generates a random number, and the player tries to guess it correctly.

Use your logic, follow the hints, and discover the hidden number! 🧠
